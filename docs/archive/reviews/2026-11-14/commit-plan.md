### Исходные изменения владельца

- `feat(calls): add hybrid calling and media migration` — `core/services/chat/internal/calls/`, `core/services/chat/internal/{server,repository}/calls*.go`, миграции Chat 13–16, `core/services/gateway/internal/{livekitproxy/,proxy/calls*.go}`, `core/shared/proto/axon/calls/`, `core/deploy/{Dockerfile.calls-*,docker-compose.calls-*.yml,calls-*}`, `ui/web/{e2e/calls-*,playwright.calls-*.config.ts,src/components/calls/,src/lib/calls/,src/lib/query/calls*,src/calls-push-worker.ts,src/app/(app)/calls/}`, `docs/calls*.md`, `.claude/plans/calls-*.md`. Плюс исходные фрагменты wiring в сохранённых patch-снимках, включая общие файлы команд Chat и Gateway.
- `feat(game): add the tic-tac-toe service and web client` — исходные части `core/services/game/`, `core/shared/proto/axon/game/`, `core/services/gateway/internal/proxy/game.go`, `ui/web/{e2e/tic-tac-toe.spec.ts,src/app/(app)/games/,src/components/games/,src/lib/query/games.ts,src/lib/ws/use-game-socket.ts}` и wiring из снимков.
- `feat(chat): extend directory, session and upload flows` — исходные отслеживаемые файлы из обоих снимков после выделения Calls/Game. В частности, поиск Auth, SQL и тесты Chat, sidebar/people directory, session identity, compression и upload preflight. Существующий staged набор остаётся со своей исходной правкой, в том числе в общих файлах из таблицы. Новые файлы этих функций сверяются с их сценариями и документами.
- `chore: align dependencies and local tooling` — исходные изменения `.mcp.json`, `CLAUDE.md`, `.claude/rules/infra.md`, `.gitignore`, `.golangci.yml`, исходные части lockfiles, compose и Dockerfile. Локальные `AGENTS.md`, `.codex/`, корневые npm-файлы и автогенерируемый `ui/web/next-env.d.ts` включать только после подтверждения назначения.

Запланированный порядок: исходная группа → SEC-04/DEP-01 → SEC-02/03 и остальные audit-коммиты → backup → отчёт. Для смешанных и новых файлов собирать будущий коммит по фрагментам. Перед staging запросить подтверждение владельца для фрагментов в новых файлах Calls/Game, где исходного снимка нет. Каталог `.local/` содержит незатреканные файлы с локальными данными и не входит в план.
