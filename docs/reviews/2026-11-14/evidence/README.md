# Доказательства ревью Axon

Здесь выдержки из локальных журналов 14–15 ноября 2026 года и результаты повторной проверки. В выдержках сохранены статусы, результаты тестов, версии, идентификаторы advisory и агрегаты. Данные тестовых аккаунтов, заголовки с секретами, внутренние адреса, локальные пути и идентификаторы ресурсов из журналов исключены. Исходники лежат в локальном каталоге доказательств.

`browser-regression-fixed.log` содержит десять прошедших chat/media проверок и падение отдельной security проверки в том же прогоне. Security и Game в отдельном прогоне прошли, см. `browser-acceptance.log`. `go-final-security.log` содержит выдержку из четырёх проверок бинарников.
