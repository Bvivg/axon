# Chat — лента и поле ввода (срез 1 переноса из nod)

Общий план: `chat-port-from-nod.md`.

## Контекст

Лента на `@tanstack/react-virtual` при подгрузке истории сверху сдвигала экран и
теряла кадр, чат открывался всегда внизу, имя и аватар повторялись у каждого
сообщения, поле ввода было однострочным. В nod те же места доведены — переносим
поведение под Next.js + Base UI.

Результат: лента держит экран при подгрузке, открывается на первом непрочитанном,
умеет «вниз» и переход к сообщению через страницы истории, рисует серии; поле
ввода многострочное.

## Решения

- `virtua` `Virtualizer` в `ScrollArea` (viewport — `scrollRef`), `shift` только на
  подгрузку сверху (первый id сменился, последний — нет), `overflow-anchor: none`,
  распорка `grow` прижимает короткий тред к низу. Первый показ скрыт, пока высота не
  устоится (2 одинаковых кадра, максимум 30).
- Строка виртуализатора — серия (`lib/chat/series.ts`): один автор, разрыв < 5 мин,
  тот же день, ≤ 30 сообщений. Аватар собеседника — один на серию, `sticky` у низа
  колонки; «хвост» пузыря — только у последнего; имя в группах — у первого.
- Разделитель «Unread messages» — по `last_read_seq` на момент открытия (замораживается
  на комнату), свои сообщения не считаются. Если он выше экрана — чат открывается
  на нём, иначе внизу.
- Кнопка «вниз» (в nod её нет, добавлена): видна вне низа, счётчик — чужие сообщения
  новее последнего увиденного.
- Переход к сообщению (цитата ответа, далее поиск): `TranscriptHandle.reveal(id)`,
  центрирование по кадрам, пока строка меряется; не найдено — подгрузка страницы,
  до 20 страниц. На время перехода подгрузка по прокрутке придержана 1,5 с.
- Страница истории — 100 сообщений (было 50 по умолчанию): лимитер gateway — 2
  запроса/с с запасом 12, переход на 7 страниц выбирал его. На `ResourceExhausted`
  переход ждёт 1 с и повторяет, а не обрывается.
- `MarkRead` — через 250 мс и только когда человек смотрит в окно
  (`lib/hooks/use-attention.ts`: вкладка видна, окно в фокусе, активность < 15 с).
- Ссылки — `linkifyjs`, только `http(s)`/`mailto`, `target=_blank`,
  `rel="noopener noreferrer"`.
- Поле ввода — `Textarea` (`field-sizing-content`, до `max-h-40`), Enter — отправить,
  Shift+Enter — перенос, IME-ввод не отправляет.
- Пункт «сообщение сокета во время первой загрузки через `QueryCache.subscribe`» из
  общего плана не нужен: в axon доставленное по сокету живёт в своём состоянии
  (`use-chat-socket.ts`, `delivered`) и сливается с историей, а не пишется в кэш.
- `vitest` для чистой логики (`make web-test`, шаг CI «Unit tests»).

## Проверка

- `make web-check` (lint, typecheck, vitest 14/14, build).
- Живьём, headless Chromium, тред 3000 сообщений: подгрузка истории 6/6 раз — 0 px
  сдвига и 0 кадров без якорной строки, в DOM 21 строка; открытие — разделитель в 8 px
  от верха; переход к цитате на 7 страниц назад — 1,4 с, по центру ±0 px.
- ui-verifier: серии, дни, «вниз», ссылки, рост поля, 375 px, тёмная тема — PASS.
- `ui/web/e2e/transcript.spec.ts`: открытие на непрочитанном, «вниз», переход к
  цитате, Shift+Enter, ссылка; `make test-web-e2e`.

## Критерий готовности

Лента не дёргается при подгрузке, открывается на непрочитанном и переходит к
сообщению через страницы истории; e2e и `make web-check` зелёные.
