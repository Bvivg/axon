# Большие сообщения и сжатие WebSocket

Один текст передаётся одним сообщением и сохраняется одной записью. Per-message deflate без сохранения словаря между сообщениями включается на обоих участках browser → gateway → chat. Дополнительные внешние доступы не нужны.

Лимит текста — 65 536 Unicode code points в UI, Go и SQL; лимит распакованного WebSocket-сообщения чата — 1 МиБ с запасом под JSON. Другие сокеты сохраняют прежние настройки. Клиент больше не делит текст; ошибки и отслеживание подтверждений сохраняются.

Файлы: shared/pkg/ws (настройка сжатия), gateway wsproxy и wiring, chat WS/domain и миграция 000012, web socket/composer/валидация/forward dialog, тесты.

Проверки через Docker Compose: Go shared/ws + chat/domain/service + gateway/wsproxy; Vitest/TypeScript/ESLint; Playwright проверяет согласование расширения, один send и ack для текста 64 КиБ, одну запись в истории после перезагрузки, отказ для превышения лимита и ошибку транспорта. Миграция применяется на dev-стенде.

Готово, когда 64 КиБ текста сохраняются одним сообщением при согласованном сжатии, а превышение лимита не теряется молча. Без commit/push/PR.
