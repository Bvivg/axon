# Редизайн web по языку чата

## Контекст
Владелец недоволен дизайном web, но считает уже переделанный чат удачным. Цель — распространить язык
чата на все разделы, чтобы приложение выглядело как один продукт, а не как чат плюс набор лендингов.
Результат: Games, Calls, Profile, Auth и админка собраны из тех же примитивов, что и чат, на одних токенах.

Снимки «до» уже есть: `docs/archive/design/before/{light,dark}/{390,768,1440}/*.png`. Учтите, что чат там
снят со старого Docker-образа, а не с текущего рабочего дерева.

## Язык чата (что берём за эталон)
- **Список и деталь.** Колонка-список (заголовок, кнопка действия, поиск) и панель-деталь с шапкой
  50px: аватар или иконка, название, иконки действий справа.
- **Контент вместо обрамления.** Нет заголовков страниц, хлебных крошек, подзаголовков-пояснений,
  hero-баннеров и градиентов.
- **Строка списка** (`RoomListItem`): аватар 32px, название с временем, подпись, бейдж-счётчик справа.
- **Сдержанный акцент.** Нейтральные поверхности, акцент только на активном, непрочитанном и главном
  действии.
- **Мягкие формы.** Пилюли и круги в композере, пузыри с «хвостом», служебные метки-пилюли
  (`Today`), иконки в шапке.

## Что ломает единство сейчас
| Экран | Проблема |
|---|---|
| Games | Маркетинговый hero «Pick a game. Bring your people.», градиентный баннер; один вход продублирован трижды (колонка, CTA, список) |
| Calls | Заголовок страницы, описание под ним (нарушает `nextjs-web.md`), крошка «← Calls», «No calls yet» и в колонке, и в центре |
| Profile | Баннер «YOUR SPACE / AXON», крошка, навигация по разделам и в колонке, и списком на странице |
| Tic-Tac-Toe | Смешение языков: «Компьютер / Игра вдвоём» рядом с английским UI |
| Auth | Шаблонная story с выдуманной перепиской «Design team», логотип дважды |
| Везде | Колонка 320px на Calls/Profile/Games почти пустая |
| Токены | Чат использует синий (`#087fb9`/`#168dc9`) в композере, всё остальное — фиолетовый `signal` |
| CSS | `workspace.css` — второй стиль поверх Tailwind: ~30 захардкоженных hex, переопределённая шкала шрифтов, метки 9–10px |

## Подход
1. **Токены** (`app/globals.css`). Один акцент — фиолетовый `signal` (решение владельца 2026-11-19),
   синий композера убран. Hex из `--workspace-*` перенести в `@theme`: `surface`, `surface-raised`, `line`.
   Одна типографическая шкала, без переопределения `--text-*` внутри `.workspace-shell`. Время и
   подпись строки списка остаются 10/11px, как в чате.
2. **Примитивы из чата** (`components/ui/`):
   - `ListColumn` — шапка колонки с заголовком, action-кнопкой и поиском (из `chat-sidebar.tsx` и
     `sidebar-search-field.tsx`);
   - `ListItem` — строка списка (из `room-list-item.tsx`);
   - `PaneHeader` — шапка детали (из `.chat-workspace-header`);
   - `EmptyState` — иконка, одна фраза и действие в одном блоке.

   `RoomListItem` и шапку чата переписать на эти примитивы без визуальных изменений.
3. **Разделы по схеме «список и деталь»:**
   - Calls: в списке история звонков строками `ListItem` (направление, время, длительность); деталь —
     контакт и действия «позвонить»; пустая деталь — `EmptyState` с «New call». Убрать
     заголовок, описание и крошку.
   - Games: в списке игры и мои партии, «твой ход» как бейдж непрочитанного; деталь — лобби или
     партия с `PaneHeader`. Удалить hero, баннер и дубли входа. Строки лобби на одном языке.
   - Profile: в списке разделы (уже есть); деталь — содержимое раздела с `PaneHeader`. Убрать баннер
     и дублирующий список на странице.
   - Admin (gateway, service map, roles): те же `PaneHeader` и `ListColumn`.
4. **Auth.** Одна форма по центру на фоне `background`, логотип над ней. Story и выдуманный
   чат удалить.
5. **Чистка.** Из `workspace.css` оставить только grid оболочки и мобильную стеклянную панель, остальное
   перевести в utility-классы. Удалить классы `games-*`, `profile-banner`, `auth-story`,
   `call-history-hero`.

Мобильная схема остаётся как в чате: список, по тапу переход в деталь, назад в шапке.

## Порядок
Токены → примитивы (чат визуально не меняется) → Profile → Calls → Games → Auth → Admin → чистка CSS.
Каждый шаг — отдельный коммит `feat(web): ...`.

## Как проверяется
- `cd ui/web && npm run typecheck && npm run lint && npm test`: всё зелёное.
- `npm run test:e2e` на Docker-стенде: существующие сценарии чата, звонков и игры проходят.
- Набор «после» снимается тем же скриптом, что `docs/archive/design/before` (страницы × light/dark ×
  390/768/1440) в `docs/design/after/`. Axe — 0 violations.
- Живая проверка на `https://axon.test` после пересборки web-образа: чат пиксельно не изменился,
  остальные разделы используют те же шапку, строки и пустые состояния.

## Критерий готовности
На любом экране, кроме самой игровой доски и сцены звонка, нет элементов, которых нет в чате:
ни заголовков страниц, ни баннеров, ни захардкоженных цветов.

## Расхождения с замыслом (по ходу работы)
- Примитивы: `ListColumnHeader`, `ListItem`/`ListIcon`/`ListBadge`/`ListLabel`, `ListSearchField`,
  `Pane`/`PaneHeader`/`PaneSection`. `WorkspacePage` и `ProfilePage` оставлены тонкими обёртками над `Pane`.
- Calls: деталь — звонки с выбранным собеседником; полный список с фильтрами — `/calls?view=all`.
- Games: в колонке каталог и партии в процессе («Your move» как бейдж), лобби — две карточки действий и
  история. Экран самой партии (русский, свои игровые токены) не менялся — язык игры остаётся открытым вопросом.
- `Topbar`, `AccountMenu`, `NotificationsMenu`, `ConnectionPill` нигде не рендерятся, но удаление файлов и их CSS
  требует согласования по аудиту — оставлены.
