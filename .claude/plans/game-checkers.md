# Шашки — четвёртая игра на общем движке

## Контекст
`CLAUDE.md` обещает, что новая игра — это только её домен за интерфейсом `Game`, без переделки
инфраструктуры. Шашки значатся в списке игр, но их нет. Добавляем английские шашки (American
checkers) и честно меряем, что пришлось тронуть вне `games/checkers`.

Результат: в вебе можно создать партию в шашки, сыграть её вдвоём до победы, посмотреть как
зритель и в повторе, потренироваться против простого бота; партия идёт через журнал, проекцию,
рейтинг и турниры так же, как остальные игры.

## Правила
- Доска 8×8, по 12 простых, играют тёмные поля, первыми ходят чёрные (место 0), белые — место 1.
- Простая ходит и бьёт только вперёд по диагонали, дамка — на одно поле в любую сторону,
  «летающих» дамок нет.
- Бить обязательно, серию можно выбрать любую (не обязательно самую длинную), многоходовое
  взятие продолжается в том же ходе; снятые шашки убираются сразу, на исходное поле можно
  вернуться.
- Простая, дошедшая до последнего ряда, становится дамкой, и ход на этом заканчивается.
- Нет хода — поражение. Ничья по соглашению — общий механизм сессии (как у шахмат). Автоничья
  после 40 ходов каждой стороны без взятия и хода простой (`QuietLimit = 80` полуходов).
- Жёсткий лимит `MaxPlies = 500` полуходов — ничья (`CheckersEnd.MOVE_LIMIT`). После слияния #29
  шашки регистрируются так же, как шахматы и Quoridor: `Definition.MaxPlies` из
  `GAME_CHECKERS_MAX_PLIES` (по умолчанию `checkers.MaxPlies`), `State.MoveLimit` и
  `Session.move_limit` выставляет общий `Advance`. Проверка в движке оставлена как верхняя граница
  и источник `CheckersEnd.MOVE_LIMIT` для доски: значение выше 500 из env её не поднимает.
- Нотация: поля 1–32, `11-15` — ход, `22x15x6` — серия взятий. Разбор ограничен по длине
  (`MaxNotation = 38`, не больше 13 полей), без паник; разбор и печать проверены fuzz-тестом.

## Решение
- **Движок** `core/services/game/internal/games/checkers/`: `board.go` (поля, геометрия,
  строковая позиция из 32 символов `.bBwW`), `move.go` (нотация), `rules.go` (генерация ходов,
  обязательное взятие, серии, превращение), `checkers.go` (`Game`, `View`). Состояние —
  `{"board", "moves", "quiet", "end"}`.
- **Контракт** (`game.proto`, только добавления): `CheckersBoard` (32 `CheckersPiece`, ходы,
  последний ход, допустимые ходы, `CheckersEnd`, `quiet_plies`), `Session.checkers = 23`,
  `HistoryFrame.checkers = 8`, команда `SessionCommand.checkers_move = 8` (`CheckersMove`).
- **Сервис game**: регистрация в `cmd/game/main.go`; в `server` — стартовая доска ожидающей
  партии, `board()`, кадр повтора, команда сокета и маппинг ошибок в `ILLEGAL_MOVE`.
  Журнал и проекция обобщённые (`Rules.Redo` по ключу игры), меняются только тесты.
- **Турниры**: `checkers` в списке игр по умолчанию `TOURNAMENT_GAMES`. Рейтинг обобщён по
  ключу игры — без изменений. Gateway — без изменений, новых процедур нет.
- **Бот**: боты в проекте живут в вебе (режим тренировки), поэтому бот шашек — там же:
  берёт самое длинное взятие, превращение и ход, после которого соперник бьёт меньше всего.
- **Веб**: `components/games/checkers/` (`board.tsx` — только отрисовка и ввод,
  `match.tsx` — партия через сокет, `practice.tsx`), правила для тренировки и бот в
  `lib/games/checkers*.ts`, маршруты `app/(app)/games/checkers/…`, запись в каталоге, повтор,
  зрители, турниры (через `gameKeys`).
- **SwiftUI** не трогаем — доска для приложения делается в другой ветке.

## Как проверяется
- `cd core && go test -race ./services/game/... ./services/tournament/...` — perft от начальной
  позиции 7/49/302/1469/7361 (и дальше 36768/179740/845931), таблицы правил, случайные партии,
  fuzz нотации.
- `make lint` — 0 замечаний; `go test -tags integration ./services/game/integration/...`.
- Go e2e `core/services/game/e2e/checkers_test.go` на одноразовом стеке `axon-checkers`:
  партия из 21 полухода через gateway до блокировки белых, с превращением, зрителем, списком
  живых партий и повтором.
- Веб: `npx tsc --noEmit`, `npm run lint`, `npm test` (perft TS-правил совпадает с Go),
  Playwright `e2e/checkers.spec.ts` — два браузера играют ту же партию до победы.
- Живая проверка в браузере на стенде `axon-checkers`: создать, присоединиться, ход, взятие,
  дамка, победа, повтор.

## Критерий готовности
Партия в шашки играется в вебе от создания до победы и повтора, а вне `games/checkers` изменены
только точки подключения, перечисленные в результатах.

## Результаты
- Движок: 13 тестов (67 подтестов), perft 7/49/302/1469/7361/36768/179740/845931 совпал с
  опубликованным; fuzz нотации; случайные партии; короткая партия из 21 полухода до блокировки.
  TS-правила для тренировки дают тот же perft до глубины 5.
- `make lint` — 0 замечаний; `go test -race` по game и tournament — зелёный; интеграционные тесты
  game (testcontainers) — зелёные.
- Go e2e на одноразовом стеке `axon-checkers`: партия через gateway до победы чёрных,
  превращение, зритель, список живых партий и повтор. Пришлось разнести ходы на 300 мс:
  сокет режет команды лимитом 4/с с запасом 8.
- Веб: `tsc --noEmit` и eslint чистые, vitest 155/155 (17 — шашки). Playwright на одноразовом
  стеке: `checkers.spec.ts` (две партии: двое игроков с зрителем до победы и повтор, тренировка)
  и регрессия chess/quoridor/tic-tac-toe/spectate/navigation/workspace-design — 19 из 19.
- Живая проверка в браузере на стенде `axon-checkers`: создание, вход вторым игроком, ход,
  обязательное взятие, двойное взятие по шагам с превращением, победа блокировкой, повтор;
  тёмная и светлая темы, тренировка против бота.
- Номера полей: 22 в `Session` и 7 в `HistoryFrame` заняты в PR #29 (`move_limit`, `move`),
  поэтому у шашек 23 и 8.

### Что пришлось изменить вне `games/checkers`
Продакшен-код:
- `core/services/game/cmd/game/main.go` — регистрация движка (1 строка и импорт).
- `core/services/game/internal/server/handler.go` — стартовая доска ожидающей партии и ветка
  в `board()` (+9 строк).
- `core/services/game/internal/server/spectate.go` — ветка кадра повтора (+4 строки).
- `core/services/game/internal/server/socket.go` — команда `checkers_move` и маппинг ошибок
  (+16 строк).
- `core/services/game/internal/server/checkers.go` — новый: снимок движка → proto.
- `core/services/tournament/cmd/tournament/main.go` — `checkers` в `TOURNAMENT_GAMES` по умолчанию.
- `core/shared/proto/axon/game/v1/game.proto` — добавления контракта.

Только тесты: `internal/journal/fold_test.go` (шашки в случайном replay свёртки),
`internal/server/checkers_test.go`, `e2e/checkers_test.go`.

Без изменений: правила сессии, журнал и компактные события, проекция, владелец партий,
матчмейкинг, рейтинг (потребитель в game и сервис rating), сага турниров, gateway.

Честный вывод: обещание «только домен» выполняется для хранения, журнала, рейтинга и турниров,
но не для представления — `server` всё ещё перечисляет игры в `present`/`board`/`historyFrame`,
в `oneof` команд сокета и в маппинге ошибок. Обобщённый `View()` в интерфейсе `Game` убрал бы
это, но меняет интерфейс — отдельная задача.

### Не сделано

  крестикам-ноликам — нужен кейс и доска.
- Генератор нагрузки `cmd/loadgen` шашки не гоняет.
